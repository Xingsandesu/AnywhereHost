# 身份与授权

iroh 使用 EndpointId 对双方身份进行认证并提供端到端加密。relay 只转发密文。Host 身份持久保存；手机为每个 Host 生成设备 Ed25519 密钥，保存在仅本设备可用的 Keychain，不内置共享服务端秘密。

配对二维码包含 Host 身份、256 位随机凭据和过期时间。Host 单次只接受一个配对请求，凭据有效期 120 秒；重新生成立即替换，首次成功授权后消费。凭据只在已验证 Host 身份的加密连接内提交。相同已授权设备重复确认不会重复授权；撤销后已消费凭据不能恢复权限。

最多授权 32 台设备。设备撤销持久保存，并关闭该身份的连接与流。生成配对凭据与设备管理仅限[本机管理 socket](API.md)。未授权连接仅可办理接入资格与配对，15 秒后关闭。服务限制 64 个连接、每连接 16 条并发流、全局 64 条活动流；首包读取与发送进度均有时限。

[远程桌面](REMOTE-DESKTOP.md)单独启用和认证。[通知服务](APNS.md)的 HTTPS 推送独立于 iroh 连接。

官方应用验证、签名接入资格、过期与撤销边界见[网络接入](RELAY.md)。

App Attest 证明应用身份，不代表用户授权。配对二维码是有效期内的授权凭据；设备私钥与有效接入证书泄露可导致身份冒用。relay 可观察连接元数据，但无法解密业务内容。
