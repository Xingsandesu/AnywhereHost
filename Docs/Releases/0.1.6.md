AnywhereHost 0.1.6（macOS 构建号 9，Debian 包版本 0.1.6-1）。

- 修复 Linux 应用内更新检查被 GitHub API 以 HTTP 415 拒绝的问题，使用正确的 JSON 请求头；安装包下载继续使用二进制媒体类型。
- Mac arm64 包使用 Developer ID Application 签名、Apple 公证及装订票据，并验证 Gatekeeper。
- Linux 提供原生 Debian 13 amd64 / arm64 包，包含 GTK 管理界面、Rust Host、frpc 和桌面共享 helper。
- 继续使用 0.1.5 配置的 OTA 密钥。GitHub 正式发布自动生成 Sparkle 清单、两个 Debian Ed25519 签名及 SHA256SUMS，并在发布前后验证。
- 发布后从两个实际 Debian 包提取更新器，验证公开更新发现、下载、签名与版本检查；不在用户环境执行安装。

**旧版用户请手动安装一次 0.1.6，之后可通过应用内 OTA 升级。** Mac 0.1.5 已使用同一更新身份，也可直接 OTA 到本版；Linux 0.1.5 的检查更新问题需要通过手动安装本版修复。

Mac：下载 ZIP，解压并将 AnywhereHost.app 放入“应用程序”。Debian：下载对应架构的 deb，运行 `sudo apt install ./anywhere-host_0.1.6-1_amd64.deb`（arm64 使用对应文件）。安装保留配对、配置及 Codex 数据；重启会中断当前远程连接。

Mac 需要 Apple Silicon / macOS 14+；Linux 发行包针对 Debian 13。Codex 使用用户已安装的 App / CLI，不随 Host 分发。真实桌面替换安装和手机端端到端验收不包含在 CI 验证内。
