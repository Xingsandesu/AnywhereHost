AnywhereHost 首次独立公开发布，适用于 Apple Silicon / macOS 14+。

- 显示版本号与构建号，新增“检查更新…”。
- 保存隧道启动状态，App 重启或 OTA 后自动恢复；主动停止后保持停止。
- 接入 GitHub Releases + Sparkle 签名 OTA；旧版需先手动安装本版。
- 改善远程桌面转发：细粒度数据块、即时 TCP 输入、避免活动连接探测干扰、慢写保护和断线日志。
- 新增心跳与 4 MiB 转发回归，整理构建、安全、协议和排错文档。

配套原生 iPhone 客户端 Anywhere 正在上架中，客户端源码不在本仓库。客户端心跳修复需要独立更新手机 App，Host 更新不能替代客户端更新。真实手机拖动链路仍待验收。

本包使用 Apple Development 签名，尚未 Developer ID 公证；首次启动可能需在 macOS“隐私与安全性”中允许。OTA 安装包使用独立 Ed25519 签名验证。
