AnywhereHost 0.1.5（macOS 构建号 8，Debian 包版本 0.1.5-1）。

- macOS arm64：Developer ID Application 签名、Apple 公证、装订公证票据并验证 Gatekeeper，适用于 Apple Silicon / macOS 14+。
- Linux amd64 / arm64：原生 Debian 13 deb，包含 GTK 4 管理界面、Rust Host、固定校验和的 frpc，以及 Wayland / X11 桌面共享 helper。
- GitHub Actions 持续构建三个平台；主分支构建成功后自动签名、公证和发布预发布包。正式发布入口额外生成 Sparkle 更新清单和两个 Linux OTA 签名，全部文件附 SHA256 校验和。
- Linux 设置向导、权限检查、配对与撤销、隧道、后台驻留和状态菜单。
- 独立的桌面共享密码保存按钮支持 Host 离线和共享已开启时保存，并明确提示校验或保存错误。
- 修复多台 Host 共用 frps 时的固定代理名冲突，使用稳定的每台 Host 唯一名称并迁移旧配置。
- 修复只读 Codex smoke 在共享模式下意外调用 thread/resume 的问题。

安装：Mac 下载 ZIP 后将 `AnywhereHost.app` 放入“应用程序”；Debian 下载与本机架构匹配的 `.deb`，使用 `sudo apt install ./anywhere-host_0.1.5-1_amd64.deb`（arm64 使用对应文件）。安装或重启会中断当前远程连接；配对、配置和 Codex 数据保持原样。

本版建立新的 OTA 更新身份。**旧版本请手动安装一次 0.1.5；此后可通过应用内 OTA 升级到后续正式版。** GitHub 正式发布流程自动生成新版本 Sparkle 清单和两个 Debian 包的 Ed25519 签名，私钥保存在 GitHub Secrets，发布前和公开下载后都会验证。后续发布沿用本版更新身份，不再每次生成密钥。

Linux 发行包针对 Debian 13，不保证兼容其他发行版。Codex 仍使用用户已安装的 App / CLI，不随 Host 分发。配套 iPhone 客户端独立发布；本次不宣称完成真实手机远程桌面的端到端验收。
